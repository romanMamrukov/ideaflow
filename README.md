# IdeaFlow MVP v0.1

Бесплатное offline-first PWA для записи идей, управления целями и небольшими задачами.

## Возможности

- Создание, редактирование и удаление идей
- Категории, приоритеты, статусы, поиск и фильтрация
- Задачи внутри идей и расчёт прогресса
- Локальное хранение в браузере
- Резервное копирование и восстановление JSON (импорт заменяет все записи)
- PWA, кэширование для offline после первого открытия

## GitHub Pages без пользовательских GitHub Actions

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, folder **/(root)** → Save.

URL: https://romanmamrukov.github.io/ideaflow/

## Ограничения

Нет облачной синхронизации, аккаунтов, AI и push-уведомлений. Данные локальны для конкретного браузера и могут быть удалены при очистке его данных. Перед очисткой экспортируйте JSON. Тестируйте импорт на копии данных. GitHub Pages может использовать внутренний механизм публикации GitHub; пользовательские workflow-файлы не нужны.
